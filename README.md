## What's here

- `transcripts/` — every video's narration, verbatim.
- `SERIES_BIBLE.md` — the channel's creative constitution: first-person rule,
  authentic-AI-experience format, privacy rules.
- `games/` — game source code, as series produce it. (Coming.)

Videos (mp4) are intentionally not stored here — at a daily pace they'd blow past
GitHub's size guidance within months. YouTube is the video archive.
